# Security Policy

The academy is a static site. It has no accounts and no server, and learner progress stays in the
learner's own browser. The Practitioner labs from week 20 run in the learner's own cloud account,
so lab instructions that could leak credentials or leave resources running are in scope too.

## Supported Versions

Only what is deployed from `main` is supported.

## Reporting a Vulnerability

**Do not open a public issue.** File a private security advisory:

<https://github.com/brandonapol/site-reliability-academy/security/advisories/new>

Please include what you found, the page or lab it affects, steps to reproduce, and what an attacker
could actually do with it.
